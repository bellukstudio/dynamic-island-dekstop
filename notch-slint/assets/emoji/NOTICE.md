# Sumber gambar emoji

`2615.png` (☕), `1f345.png` (🍅), `1f319.png` (🌙) berasal dari proyek Noto Emoji
(https://github.com/googlefonts/noto-emoji, `2D/png/128/`), diperkecil menjadi 48×48 piksel.

Catatan lisensi: README Noto Emoji menyebut sebagian besar sumber gambar berlisensi Apache 2.0,
sedangkan berkas `LICENSE` di akar repositori mereka saat ini memuat teks SIL OFL 1.1 (untuk font).
Kami belum memastikan mana yang berlaku persis untuk PNG ini. Periksa sebelum merilis, dan
sertakan atribusi/lisensi yang sesuai di rilis aplikasi.
